# SOP-QA-012 INSP 이상 Lot 1차 판정

| 항목 | 내용 |
|---|---|
| 문서 번호 | SOP-QA-012 (샘플) |
| 버전 | 1.0 |
| 담당 | 품질팀 |
| 대상 | INSP(검사) 공정을 마친 Lot |
| 목적 | 검사 결과로 Lot 의 이상 여부를 1차 판정하고, 엔지니어 확인이 필요한 Lot 을 빠르게 걸러낸다 |

> Coris 스킬 작성 샘플용 문서입니다. 기준값(150개/장, OOC 3건)은 Mock 데이터에 맞춘 예시입니다.

## 1. 입력
- Lot ID

## 2. 절차

| 단계 | 할 일 | 확인 시스템 |
|---|---|---|
| 1 | Lot 의 INSP 결과(웨이퍼별 defect 수 · 유형 · 자동 분류 패턴 · 직전 공정 설비)를 조회한다 | INSP |
| 2 | 이상 웨이퍼를 선별한다 — 기준 초과 웨이퍼, 자동 분류 패턴(Edge · Center · Scratch · Cluster) 웨이퍼 | — |
| 3 | 이상 웨이퍼가 없으면 **정상** 으로 판정하고 7단계로 간다 | — |
| 4 | 이상 웨이퍼가 거친 **직전 공정 설비**를 모은다 (중복 제외) | — |
| 5 | 각 설비의 최근 7일 **막 두께 지표**를 조회해 관리한계 이탈(OOC) 건수를 확인한다 | 설비 지표 |
| 6 | 아래 **판정 기준**으로 Lot 을 판정한다 | — |
| 7 | **보고 양식**으로 정리한다 | — |

## 3. 판정 기준

| 판정 | 조건 | 조치 |
|---|---|---|
| 정상 | 이상 웨이퍼 없음 | 다음 공정 진행 |
| 관찰 | 패턴 웨이퍼만 있고, 관련 설비 OOC 가 모두 3건 미만 | 진행하되 다음 Lot 에서 같은 설비 · 패턴 재발 여부 확인 |
| 엔지니어 확인 요청 | 기준 초과 웨이퍼가 1장 이상 **또는** 관련 설비 중 OOC 3건 이상 | Lot Hold 검토 요청, 담당 엔지니어 확인 |

- 웨이퍼당 defect 기준: **150개**
- 설비 지표 기준: 최근 7일 막 두께 OOC **3건 이상**이면 설비 의심
- 여러 조건에 걸리면 더 높은 단계(엔지니어 확인 요청)로 판정한다

## 4. 보고 양식
1. 판정 한 줄 — `판정: {정상 | 관찰 | 엔지니어 확인 요청}` 과 핵심 근거
2. 이상 웨이퍼 표 — Slot · Defect · 패턴 · 직전 설비
3. 설비 지표 표 — 설비 · 7일 평균 두께 · OOC 건수 · 설비 의심 여부
4. 조치 — 판정 기준 표의 조치 + 확인할 항목 (원인을 단정하지 않는다)
