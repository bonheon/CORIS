def run(skill, question):
    inputs = LLM_뽑기(question, skill.inputs) if skill.inputs else {}
    if 필수값_없음(inputs): return 되묻기()
    보관함 = {}
    i = 0
    while i < len(skill.steps):
        step = skill.steps[i]; i += 1
        match step.type:
            data:      보관함[step.id] = 동시에([tool(채우기(step.args, 항목)) for 항목 in 목록(step.for_each)])
            compute:   보관함[step.id] = 표_만들기(step.columns, 보관함)          # 코드 계산
            condition: if 판단(step.if, 보관함): i = 위치(step.then)          # 참이면 건너뛰기
            judge:     보관함[step.id] = LLM(요약(step.from, 보관함), step.prompt, step.criteria)
            report:    return 채우기(step.template, 보관함)                    # 빈칸 채워 답변

웹에서 만드는 순서

  1. 스킬 → 새 스킬 (또는 공식 skill 을 '복제해서 내 스킬로'). 이름 · 설명 · 태그를 적습니다.
  2. 입력값이 필요하면 추가합니다 — 예: lot_id · Lot ID · 필수.
  3. 단계를 위에서부터 쌓습니다: 조회 → (조건) → 계산 → 판단 → 보고. 인자 칸 옆 '참조 넣기' 에서 앞 단계 값을 고릅니다.
  4. 저장 — 잘못 적은 곳(없는 tool, 뒤 단계 참조 등)은 저장 전에 알려 줍니다. '대화에서 실행' 으로 확인합니다.
